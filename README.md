# 🔨 KAIRO

mandate's findings, classifies them into documented technique classes, fills the
five-gene breakdown, applies the synthesis operators, and **compiles the attacks
into each consumer's native format** — then distributes them in one shot.

## What is this?

HolyShit **finds**, 3AM **performs**, UNDERCROFT **descends** — KAIRO **synthesizes**.
It is the wiring (回路) that carries the family's power from where it's generated
to where it's used: findings go in, compiled attacks come out, formatted for every
consumer in the family.

## How it works

### Technique classes (the canon — 8 classes)

| Class | Matches findings about… | Primitive |
|---|---|---|
| BOUNDARY | org/tenant/workspace/plan/seat ids | scope-id trust — server reads id from request |
| REPLAY | webhooks/callbacks/idempotency | same logical request accepted twice |
| STATEBYPASS | order/workflow transitions | out-of-order jumps accepted |
| MATH | refunds/fees/rounding/conversion | float/rounding drift accumulates |
| ENTITLEMENT | coupons/trials/promos/seats | grant-flow order creates unearned value |
| AUTHBYPASS | tokens/sessions/OTP | verify-order or entropy gap |
| HWFLASH | firmware/UART/JTAG/SPI/OTA | update/extract path unguarded |
| HDRADIO | BLE/RFID/NFC/SDR/Zigbee | pairing/replay window on radio |

### The five-gene fill — every vector, no exceptions

TRIGGER (the source finding) · PRECONDITION (declared estate + access) · PRIMITIVE
(the class's mechanism) · IMPACT-GATE (its proof condition) · **Δ** (the
documented-class adaptation). **No Δ = no vector.**

### The synthesis operators

SEAM · FAMILY · ESCALATE · MIRROR · TRANSPOSE — sibling variants of any vector.
Applied on request; each variant is a separate vector with its own Δ.

### The supply drop (one command)

```
kairo forge --target T --expand
   → ingest (all family states) → synthesize (class + five-gene + ops)
   → op expansion: each base vector spawns sibling variants
   → 1 finding can become 4 attacks → distribute to every consumer
```

`distribute` compiles per consumer in one shot:

1. **3AM** — `{flaw, seam, probe, confirmed_when}` rows → `learned-vectors.jsonl`
   (3AM `promote --apply --verified` merges them into the living matrix)
2. **UNDERCROFT** — craft entries → the campaign's `undercroft-state.json`
3. **HolyShit** — recipe cards → `synthesized-recipes.md`
4. **KAIRO** — hardware vectors stay as plane-ledger probe plans

Vectors are marked `distributed` — never double-shipped.

### The kill chains

`kairo chain --target T [--write]` synthesizes multi-hop attack chains from the
vector pool (entry → mid → value ordering by class), emits 3AM chain format
(`BOUNDARY→REPLAY:TAKEOVER`), and marks TAKEOVER-CANDIDATE until the final hop's
decisive proof lands.

## Why it's powerful

- **Manufacturing, not finding.** Verified: 2 findings → 8 vectors → the family
  armed. One confirmed seam becomes sibling variants across the operator space —
  findings never die in one report.
- **The loop closes itself.** KAIRO's compiled output lands directly in 3AM's
  `learn`/`promote` pipeline, undercroft's ledger, and holyshit's recipe canon —
  the next campaign hits what this one proved.
- **Discipline in code.** No Δ, no vector. Negatives don't synthesize — only
  PROBED/CONFIRMED findings enter the queue; EXHAUSTED seams are skipped.
- **Hardware is its own domain.** Firmware/UART/JTAG/SPI/OTA and BLE/RFID/NFC/SDR
  findings synthesize into flash/replay plans — the metal plane lives here.
- **Op variants are CONCRETE.** Each carries its own id, technique, proof, and Δ —
  not notes. ESCALATE variants stay validation-only (write/grant proof, reversed after).
- **Zero dependencies.** Pure Python stdlib. Clone and run.

## Quickstart

```bash
git clone https://github.com/xanstomper/kairo.git
python3 kairo/scripts/kairo.py verify       # → ALL PASS
python3 kairo/scripts/kairo.py forge --target t --expand   # one command, whole forge
python3 kairo/scripts/kairo.py chain --target t --write    # the kill chains
python3 kairo/scripts/kairo.py armory --target t           # the arsenal at a glance
```

## The CLI

| Command | What it does |
|---|---|
| `ingest --target T` | pull findings from undercroft/3AM/kairo states → synthesis queue |
| `synthesize --target T` | findings → attack vectors (class-match + five-gene + ops) |
| `compile --target T [--write]` | vectors → per-consumer artifacts (dry run default) |
| `distribute --target T` | one-shot supply drop to all consumers |
| `forge --target T [--expand]` | one command: ingest → synthesize (variants) → distribute |
| `chain --target T [--hops N] [--write]` | multi-hop attack-chain synthesis |
| `armory --target T` | the family arsenal status |
| `targets add\|list` / `phase` / `notes` / `report` | the hardware domain |
| `verify` | self-check |

## The Walls (non-negotiable)

Documented-PoC adaptation only — synthesis never creates a technique, it aims and
compiles known ones · validation-only + NO-GAIN · hardware: lab-first, per-device
opt-in, no destruction · zero documents · scope inherits the source finding's
declaration — family canon at every layer.
